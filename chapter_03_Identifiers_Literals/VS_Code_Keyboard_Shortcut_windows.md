## Tips & Tricks

- **Multi-Select:** Hold `Ctrl` and click to create multiple cursors
- **Column Selection:** Hold `Ctrl + Shift + Alt` and drag with mouse
- **Word Selection:** Double-click to select a word
- **Line Selection:** Click on line number to select entire line
- **Bracket Matching:** Select code and press `Ctrl + Shift + \` to go to matching bracket
- **Fast Scroll:** Hold `Page Up` or `Page Down`
- **Command Palette:** Use `>` prefix to search commands (e.g., `> format`)
- **File Search:** Use `@` prefix to search symbols (e.g., `@ function_name`)

## Navigation Tips

- `Ctrl + P` for Quick File Open - Start typing filename
- `Ctrl + P` then `@` to search symbols in file
- `Ctrl + P` then `:` to go to line number
- `Ctrl + G` Go to specific line number directly

## Customizing Shortcuts

You can customize shortcuts by:
1. Press `Ctrl + K Ctrl + S` to open Keyboard Shortcuts
2. Search for the command you want to modify
3. Click the pencil icon and enter your desired shortcut
4. Or edit `keybindings.json` directly (`Ctrl + Shift + P` > "Open Keyboard Shortcuts (JSON)")
