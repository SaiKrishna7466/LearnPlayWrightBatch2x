# LearnPlayWrightBatch2X

This repository contains beginner-friendly Playwright and JavaScript learning examples organized by chapter. It includes basics, JavaScript concepts, identifier rules, comments, and Visual Studio Code shortcuts.

## Project Structure

- `chapter_01_Basics/`
  - `01_Basics.js`
  - `02_Verify_Setup.js`
  - `03_HotCode.js`
- `chapter_02_Javascript_concepts/`
  - `04_JS_Basics.js`
  - `05_Identifier_Rules.js`
  - `06_Identifier_part2.js`
  - `07_comments.js`
  - `VS_Code_Keyboard_Shortcut_windows.md`

## Contents

- JavaScript identifier rule examples
- Naming conventions like camelCase, PascalCase, snake_case, and CONSTANT_CASE
- Single-line and multi-line comment examples
- Useful VS Code keyboard shortcuts for Windows

## Usage

1. Open the repository in VS Code.
2. Explore the JavaScript examples in `chapter_02_Javascript_concepts/`.
3. Run or modify the examples using Node.js or a browser environment.

## Notes

- This repository is primarily for learning and reference.
- The JavaScript examples are simple and meant to demonstrate core concepts.
