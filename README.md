# LearnPlayWrightBatch2X

This repository contains beginner-friendly Playwright and JavaScript learning examples organized by chapter. It includes basics, JavaScript concepts, identifier rules, comments, and Visual Studio Code shortcuts.

- `chapter_03_Identifiers_Literals/`

  - `06_Identifier_part2.js`

  - `16_Hoisting_functions.js`

## Contents

- Playwright basics and setup verification examples
- JavaScript syntax and fundamental concepts
- Identifier rules and naming conventions
- Comment examples and VS Code shortcuts for Windows
- Variable scope, function scope, and hoisting examples

## Usage

1. Open the repository in VS Code.
2. Explore the JavaScript examples in `chapter_02_Javascript_concepts/`.
3. Run or modify the examples using Node.js or a browser environment.
