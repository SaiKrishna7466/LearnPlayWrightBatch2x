# LearnPlayWrightBatch2X

A comprehensive learning repository for JavaScript, TypeScript, and Playwright testing. Contains progressive chapters covering basics, core JavaScript concepts, OOP principles, async programming, and end-to-end testing with Playwright.

## Chapters Overview

### **Chapter 1-3: Fundamentals**
- **Chapter 01: Basics** - Setup verification, environment configuration, and Hot Code Reload (HCR) introduction
- **Chapter 02: JavaScript Concepts** - Core JavaScript fundamentals and basic syntax
- **Chapter 03: Identifiers & Literals** - Naming conventions, identifier rules, comments, and VS Code keyboard shortcuts for Windows

### **Chapter 4-5: Variables & Data Types**
- **Chapter 04: Variable Scope & Hoisting** - Deep dive into `var`, `let`, `const`, function scope, block scope, and hoisting behavior
- **Chapter 05: Literals** - String literals, template literals, backticks, null, undefined, and literal types

### **Chapter 6-9: Operators & Control Flow**
- **Chapter 06: Operators** - Assignment, arithmetic, modulus, exponentiation, and comparison operators (loose vs strict)
- **Chapter 07: If-Else Statements** - Conditional logic and branching
- **Chapter 08: Switch Statements** - Switch case patterns and fallthrough behavior
- **Chapter 09: User Input** - Handling user input and interactive programs

### **Chapter 10-15: Collections & Iteration**
- **Chapter 10: Loops** - For loops, For-of, For-in, While, and Do-While loops
- **Chapter 11: Arrays** - Array methods, manipulation, and iteration patterns
- **Chapter 12: Functions** - Function declaration, arrow functions, parameters, and return values
- **Chapter 13: Strings** - String methods, manipulation, and formatting
- **Chapter 14: Objects** - Object creation, properties, methods, and manipulation
- **Chapter 15: 2D Arrays** - Multi-dimensional arrays and matrix operations

### **Chapter 16-18: Asynchronous JavaScript**
- **Chapter 16: Callbacks** - Callback functions and callback hell patterns
- **Chapter 17: Promises** - Promise creation, chaining, and error handling
- **Chapter 18: Async-Await** - Modern async-await syntax and error handling

### **Chapter 19: Playwright Basics**
- Introduction to Playwright testing framework, browser automation, and end-to-end testing fundamentals

### **Chapter 20-25: Advanced JavaScript & OOP**
- **Chapter 20: Export-Import** - ES6 modules, named and default exports, and module patterns
- **Chapter 21: Classes & Objects** - Class declaration, constructors, and object-oriented programming basics
- **Chapter 22: Encapsulation** - Data hiding, access modifiers, and encapsulation patterns
- **Chapter 23: Inheritance** - Class inheritance, super keyword, and inheritance patterns
- **Chapter 24: Polymorphism** - Method overriding, polymorphic behavior, and interface implementation
- **Chapter 25: OOP Interview Questions** - Common OOP concepts and interview preparation

### **Chapter 26-30: TypeScript**
- **Chapter 26: TypeScript Basics** - TypeScript introduction, types, and type annotations
- **Chapter 27: TypeScript Interfaces** - Interface declaration, implementation, and extension
- **Chapter 28: Enums** - Enum types, numeric and string enums
- **Chapter 29: Generics** - Generic types, constraints, and utility types
- **Chapter 30: Access Modifiers** - Public, private, protected, and readonly modifiers

### **Chapter 31-32: Advanced TypeScript & Playwright**
- **Chapter 31: Type Overrides & Decorators** - Advanced type manipulation and decorator patterns
- **Chapter 32: Playwright Fundamentals** - Comprehensive Playwright testing with TypeScript

### **Task Folders**
- **1_Tasks_05_20th_2026** - HTTP status code categorization, test verdict classification, bug severity assessment, build health reporting
- **1_Tasks_05_22_2026** - Triangle classifier, FizzBuzz tests
- **1_Tasks_06_22_2026** - Calculator and class examples
- **1_Tasks_06_8th_2026** - Pyramid pattern generation

## Usage

1. Clone the repository
2. Install dependencies: `npm install`
3. Open in VS Code: `code .`
4. Navigate through chapters sequentially for progressive learning
5. Run JavaScript files: `node filename.js`
6. Run TypeScript files: `npx ts-node filename.ts`
7. For Playwright tests: `npx playwright test`

## Learning Path

For best results, follow this progression:
1. Start with Chapters 1-5 for JavaScript fundamentals
2. Continue with Chapters 6-9 for control flow
3. Master Chapters 10-15 for collections and functions
4. Understand Chapters 16-18 for asynchronous programming
5. Learn OOP with Chapters 20-25
6. Transition to TypeScript with Chapters 26-31
7. Apply knowledge with Playwright testing (Chapters 19 & 32)
